# Apollo Resources Group Website

Premium bilingual website for Apollo Resources Group.

## Local launch

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy to Vercel

1. Upload this folder to GitHub.
2. Connect repository to Vercel.
3. Framework preset: Next.js.
4. Deploy.
